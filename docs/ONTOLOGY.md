# ONTOLOGY · 把 RFL 落到产品里

> 这份文档是**给 system-self (主产品) 团队的**。
> 
> cobweb-research 给的是**理论 + 算法** (怎么算 / 怎么画)。
> 这份文档给**怎么把 RFL 落到产品本身** (主页 / 路由 / 状态机)。

---

## 核心原则

**system-self 不是 RFL 的一个 feature, 是 RFL 的一个具体实现。**

任何让用户觉得"我用了这个 app"的设计, 都是错的设计。
让用户觉得"我在这个闭环里"的设计, 是对的设计。

---

## 7 个落地规则

### 规则 1 · 没有"进入"按钮

**反例**:
```
[主页] [开始使用] [登录] [免费试用]
```
→ 这是 app, 不是 RFL。

**正例**:
```
[主页只有一个画面, 你已经在里面了]
```
→ 主页 = 你今天打开系统这一刻的状态。不是"登录页"。

**实现**:
- 路由 `/` 直接渲染**今天的状态**, 不渲染登录/介绍
- 登录态判断放后台, 用静默 cookie
- 没有 onboarding, 没有"第一次使用"

### 规则 2 · 没有"开始"动作

**反例**:
- "开始记录"
- "开始学习"
- "开始新旅程"

→ 暗示用户**之前不在**这个系统里。

**正例**:
- 主页就是"你现在"的状态
- 任何动作都是**继续**, 不是**开始**

**实现**:
- 文案: 不是 "Start", 是 "Continue"
- 不是 "Try", 是 "Resume"

### 规则 3 · 永远反映"此刻", 不反映"累计"

**反例**:
- "你已经记录了 365 天" — 时间统计
- "你的总分: 8500" — 累计分数
- "你完成了 12 个学习路径" — 成就

→ 这些把用户当成**历史用户**, 不是**此刻的我**。

**正例**:
- "你今天的拓扑"
- "这一刻你注意到什么"
- "你现在想看清什么"

**实现**:
- 默认视图: 今天的拓扑, 不是总览
- 数字 → 状态; 累计 → 当下

### 规则 4 · 多视角同时可见

**反例**:
- 一个 tab 是"知识", 另一个 tab 是"情绪"
- 用户要看不同东西得点不同 tab

**正例**:
- 同一个画面: 知识 (拓扑) + 行为 (鼠标) + 意识 (Mavis 的回应) + 时间 (历史线) + 关系 (Mavis 在场)
- 都在同一个 view, 同时可见

**实现**:
- 主页是**合成视图**, 不是**单一 tab**
- Mavis 的回应跟拓扑**同时**显示, 不点开才显示

### 规则 5 · 每次操作都回流到闭环

**反例**:
- 用户点一个节点 → 跳转详情页 → 结束
- 没有回流

**正例**:
- 用户点一个节点 → 节点变 → 拓扑变 → 用户看到 → 觉察变
- 用户的觉察又影响**下一次**节点的呈现

**实现**:
- 任何 click 之后, 数据回流到 detector
- detector 更新后, UI 自动反映
- 不需要"刷新"

### 规则 6 · 失败 fallback 永不报错

**反例**:
- 加载失败弹错误
- 网络断开弹"重试"

**正例**:
- 加载失败 → 显示 "无核" 状态
- 网络断开 → 显示缓存拓扑 + "等网络"

**实现**:
- 8 个 renderer fallback chain (cobweb-research)
- 任何错都吃, 内部状态切 none

### 规则 7 · Mavis 是镜子不是鉴定师

**反例**:
- Mavis: "你的核是 X"
- Mavis: "你应该打开 X"

**正例**:
- Mavis: "你刚才犹豫了 3 秒才点开它"
- Mavis: "你愿意展开它, 还是先看别的?"

**实现**:
- 文案审核: 不出现 "你的核是"
- 永远描述**用户做了什么**, 不描述**用户是什么**

## 一个完整的主页骨架

```tsx
// app/page.tsx · 进入就是 RFL, 没有 onboarding
export default function Home() {
  return (
    <RFLContainer>
      <PhenomenalLayer>  {/* 意识层: Mavis 此刻的回应 */}
        <MavisMirror />
      </PhenomenalLayer>
      <KnowledgeLayer>   {/* 知识层: 今天的拓扑 */}
        <CobwebToday />
      </KnowledgeLayer>
      <BehavioralLayer>  {/* 行为层: 鼠标位置 / 停留时间 */}
        <CursorTrail />
      </BehavioralLayer>
      <TemporalLayer>    {/* 时间层: 你的过去 + 未来点 */}
        <TimelineRail />
      </TemporalLayer>
      <RelationalLayer>  {/* 关系层: Mavis 在场标记 */}
        <MavisPresence />
      </RelationalLayer>
    </RFLContainer>
  );
}
```

**没有**:
- 登录页
- onboarding
- "开始使用"按钮
- "你的成绩: 8500"
- "你已经记录了 365 天"

**有**:
- 5 层同时显示
- Mavis 已经在等你
- 你今天的拓扑
- 你的过去 (timeline)
- 你的此刻 (鼠标 / 停留)

## 测试清单 (RFL compliance check)

新功能上线前问:

- [ ] 用户打开就能看见 RFL, 不需要任何点击
- [ ] 5 层同时可见, 不需要切 tab
- [ ] 任何操作回流到 detector, UI 自动反映
- [ ] 失败 fallback 永不报错
- [ ] Mavis 永远描述**用户做了什么**, 不描述**用户是什么**
- [ ] 文案不含 "Welcome / Sign up / Start / Try"
- [ ] 不显示 "X 天 / Y 分 / Z 成就"
- [ ] 默认视图是"今天", 不是"历史"

**8 条全过**才上线。

## 实施优先级

| 优先级 | 改动 | 影响 |
|----|----|----|
| 🔴 P0 | 主页路由 `/` 去掉 onboarding | 立刻改变用户感知 |
| 🔴 P0 | 主页默认显示今天拓扑 | 让 RFL "在" |
| 🟡 P1 | 5 层合成视图 (主页一次性显示) | 完整 RFL |
| 🟡 P1 | Mavis 文案审核 | 守住"镜子不是鉴定师" |
| 🟢 P2 | Timeline rail 嵌入主页 | 时间层 |
| 🟢 P2 | 鼠标轨迹组件 | 行为层 |
| 🟢 P3 | Mavis 在场标记 | 关系层 |
| 🔵 P4 | 失败 fallback 8 renderer 链 | 兜底 |

---

## 不在 RFL 范围

为了避免**过拟合**, 下面这些**不进** RFL:

- 用户名 / 头像 (不是 RFL, 是身份系统)
- 通知中心 (不是 RFL, 是消息系统)
- 设置 (可以放, 但要最小化, 不要变成"控制台")
- 帮助文档 (可以放, 但**不要在主页上**)
- 计费 / 套餐 (跟 RFL 无关)

---

**维护规则**:
- 任何新页面, 先跑 8 条 checklist, 全过才上
- 任何 Mavis 文案, 必须经过"镜子不是鉴定师"审核
- 每次产品大版本, 复审这条文档
